# Piper Landing Page

Static, single-file landing page for Piper — a growth engine for appointment-based businesses.

## Files

- `index.html` — the entire page (HTML, CSS, and content all inline).
- `piper-logo.png` — favicon / apple-touch-icon.

## Local preview

Just open `index.html` in a browser, or serve the directory with any static server:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

Drop the directory onto any static host (Netlify, Vercel, Cloudflare Pages, S3, GitHub Pages, etc.). No build step.
